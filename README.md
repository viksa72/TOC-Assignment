# ⚙️ Turing Machine Simulator
### Theory of Computation — Interactive Visualizer

A premium, interactive web-based **Turing Machine Simulator** built for Theory of Computation (TOC) exploration. This tool allows you to visualize state transitions, tape movements, and computation logs in real-time.

---

## Key Features

- **Dual-Engine Support**:  Local Browser Engine +  Server-side Compute Engine.
- **Interactive Visual Tape**: Smoothly animated infinite tape with automatic focus tracking.
- **Classic TOC Presets**: Built-in machines for bit flipping, binary increment, aⁿbⁿ, and palindromes.
- **Custom Rule Editor**: Pro-grade syntax editor for creating and testing your own Turing logic.
- **Live Computation Log**: Full audit trail of every transition, state shift, and tape modification.
- **Modern UI**: Dark glassmorphic design for a premium, high-contrast visual experience.
